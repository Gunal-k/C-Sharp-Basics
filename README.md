# C# Basics

A beginner-friendly repository to learn the fundamentals of **C#** and the **.NET ecosystem** through simple examples, explanations, and hands-on practice.

This repository is part of my journey to becoming a **Software Developer**, where I document everything I learn while building a strong foundation in C#.

---

## 📚 Topics Covered

* ✅ Introduction to C#
* ✅ Variables & Data Types
* ✅ Operators
* ✅ Type Casting
* ✅ User Input & Output
* ✅ Conditional Statements (`if`, `else`, `switch`)
* ✅ Loops (`for`, `while`, `do-while`, `foreach`)
* ✅ Methods
* ✅ Arrays
* ✅ Strings
* ✅ Exception Handling
* ✅ Object-Oriented Programming (OOP)

  * Classes & Objects
  * Constructors
  * Encapsulation
  * Inheritance
  * Polymorphism
  * Abstraction
* ✅ Collections
* ✅ File Handling
* ✅ LINQ Basics
* ✅ Delegates & Events
* ✅ Asynchronous Programming (`async` / `await`)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Gunal-k/C-Sharp-Basics.git
```

Navigate to the project:

```bash
cd C-Sharp-Basics
```

Run a project:

```bash
dotnet run
```
